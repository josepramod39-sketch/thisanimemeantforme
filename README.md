# animefor

A quiet wall for loud feelings. **animefor** is a scrapbook-style wall where people
share *what an anime meant to them* — plus a calendar of what's airing next and a
reel of anime clips. Inspired by the warm, content-first aesthetic of ThisSongMeant,
tuned for an anime vibe (sakura petals, speed-line page wipes, spring pop-ups).

## Stack

- **Vite + React 19 + TypeScript**
- **react-router-dom** (with `framer-motion` `AnimatePresence` page transitions)
- **framer-motion** — scroll reveals, parallax hero, petals, micro-interactions
- **Supabase** — Postgres + anonymous auth + RLS (stories, likes, profiles)
- **AniList GraphQL** — anime search, cover art, official trailers, airing schedule
- **YouTube** — embedded anime clips & trailers via the IFrame Player API, credited to each channel

## Getting started

```bash
npm install
cp .env.example .env.local   # then fill in your Supabase URL + publishable key
npm run dev
```

Other scripts: `npm run build`, `npm run preview`, `npm run lint`.

## Environment

`.env.local` (gitignored):

```
VITE_SUPABASE_URL=https://YOUR-ref.supabase.co
VITE_SUPABASE_ANON_KEY=sb_publishable_xxx
```

These are client-side publishable values — safe to expose; access is governed by
Row Level Security.

## Supabase setup

The schema lives in `supabase/` migrations (profiles, stories, likes, and the
`stories_with_counts` feed view). RLS is enabled: everything is world-readable,
but you may only write rows tied to your own session.

> ⚠️ **One manual step:** posting and liking use Supabase **anonymous auth**.
> Enable it once in the dashboard: **Authentication → Sign In / Providers →
> Anonymous Sign-Ins → Enable**. Reading the feed works without it; writing does not.

Identity is frictionless: a per-device anonymous session is created on load, and a
handle is captured the first time you post (no email, no password).

## Project layout

```
src/
  lib/           supabase client, db access, AniList + VLIPSY/video helpers, formatters
  context/       ui (modals), session (anon auth + handle), stories (feed state)
  hooks/         useDebouncedValue, useAiringCalendar
  components/    StoryCard, MasonryGrid, Hero, modals, video/, calendar/, effects/
  pages/         FeedPage, CalendarPage, ProfilePage, NotFound
  data/          youtubeClips.ts (curated, generated by scripts/gen-youtube.mjs)
```

## Content & attribution

- Anime metadata, cover art, trailers — [AniList](https://anilist.co).
- Clips & trailers embedded from **YouTube** via the IFrame Player API, each
  credited to its channel and linking back to YouTube. The curated set is
  validated for embeddability via YouTube oEmbed — refresh with
  `node scripts/gen-youtube.mjs`.
- User stories belong to their authors.
